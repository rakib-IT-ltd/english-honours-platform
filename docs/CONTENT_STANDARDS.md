# Content Standards

> **Status:** summary of rules already fixed in [`CLAUDE.md`](../CLAUDE.md). Detailed style guidance is not yet written.

## Verification

- The official NU First Year syllabus for session 2024-2025 is the only verified baseline.
- Never invent syllabus information; never assume older syllabuses apply; never mark unverified
  courses as officially verified.
- Keep the source document and a verification record for every syllabus item.

## Editorial workflow

Draft -> Academic Review -> Approval -> Publication. AI-generated content is a draft until reviewed.

Record for every item: author, reviewer, references, publication status, versions, correction history.

## Language

English and Bangla are both first-class. Offer, where appropriate: English explanation, Bangla
explanation, academic terminology, beginner-friendly definitions, advanced discussion. Preserve literary
and linguistic terminology accurately.
